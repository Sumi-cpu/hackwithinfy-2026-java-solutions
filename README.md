# HackWithInfy Australia 2026: Java Solutions

My solutions and notes from participating in Infosys's HackWithInfy coding competition.

## What's inside
- Java solutions to algorithmic problems (arrays, strings, graphs, DP, etc.)
- Short notes on the approach and time/space complexity for each
- Lessons from the problems I couldn't solve in time, and what I'd do differently

## Key takeaways
- Break complex problems into small, solvable steps
- Stay calm and focused under time pressure
- Learn as much from the problems that stumped me as from the ones I solved
